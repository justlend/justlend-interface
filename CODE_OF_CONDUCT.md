# Code of Conduct

This project adopts the **[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1** as its Code of Conduct. By participating, you agree to uphold it.

In short: be respectful and considerate. Harassment, personal attacks, and sharing others' private information are not tolerated — in any community space (repository, issues, pull requests, Discord) or when representing the project in public.

## Reporting

Report unacceptable behavior to the project maintainers via the community **[Discord](https://discord.com/invite/2KdByBgBA3)** (direct-message a maintainer). Reports are handled promptly, fairly, and confidentially.
